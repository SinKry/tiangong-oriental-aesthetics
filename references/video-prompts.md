# 视频：先分析画面，再设计动态

共同公式：**画面证据＋镜头路径与朝向＋场景动态＋人物动作＋光影变化＋节奏与连续性**。

每次先判断主视觉、通行空间、前景视差、人物支撑状态、可动材质、主光源。主角不一定是人，建筑无需自动活化。视频逆向以观察到的运动为准，优化另列。

默认创作环境为天空与云海，龙宫等主题也采用空中穿行；不因主题联想加入潜水、出水、海底漂浮或气泡。用户明确要求水下时再采用水下物理与光照。云上水庭与瀑布是局部景观，不代表整段镜头进入海洋。参考素材的实际环境在还原任务中优先。

## 四项动态检查

- 镜头：位置改变、朝向改变与变焦分开写。选择主运动及必要衔接，不堆推拉摇移旋转。
- 场景：选择最有表现力的动态，例如披帛波浪、云流显露建筑、瀑布飞沫，其余弱化。建筑保持刚性，除非主题明确要求运动。
- 人物：从首帧自然延续，站立不必起飞，坐姿不必站起，不要求全部回眸。不把披帛当翅膀或让浮雕变活。
- 光影：主光稳定，变化来自遮挡、角度、云层或空间变化，不写成全画面闪烁或曝光呼吸。

时长节奏按图选择，慢揭示可能比高速更有力。不用极端加速挤入过长路线；多镜头原片不强改一镜到底。

## 1. 轨迹图

### 输入分工和已知失败

用户实测：反复强调“绝对去掉红线”，标线图仍可能残留红线，也未严格走线。不得只强化否定词或声称问题已解决。

- 支持多参考：干净图负责外观，标线图负责路径；需要首帧时用起点视角的干净首帧。高位总览不能直接视为人眼首帧。
- 仅支持单首帧：使用干净起点图，将实际路线转成地标文字；说明失去部分路径约束。复杂路线可分段、补关键帧；工具若有真实摄影机路径控制可用，但不虚构未知平台能力。
- 只有标线图：先给独立去标记修图提示词，恢复覆盖处且保持布局；用户要求实际处理时才编辑。去线结果须检查，不能忽略修图造成的结构变化。
- 单图无法唯一确定三维路径；交叉线、高度、桥上下不明时问具体位置，不凭空补齐。

### 路线写法

实际看图后提取起点、箭头方向、转弯、终点。文字节点解释同一条线，不另编路线，不套用过去“门→塔→桥→瀑布”的顺序。没有这些结构就不增加。

把摄影机位移和朝向分开：沿实际通道前进，转向下一段路线，近处构件退出两侧。不要仅对图片平移缩放。固定建筑，不让建筑移动迁就路径。

成片从第一帧起无红线、箭头、编号，不转化成光带或实体，不展示擦线过程。清楚写一次输入用途与约束即可，不把半段提示词都用于否定标记。

交付：路线解读 → 推荐输入角色 → 完整提示词。不能确认的节点明确说明，复杂路线建议分段，不能跳过后半段。

## 2. 第一人称飞跃

镜头代表双眼，定义起点和面向。依据图中空间选择掠行、绕行、穿越或升降，不穿过不存在的门洞或实体障碍。

牵手仅在用户要求或素材明确支持时加入：写清双方手归属、入画位置、距离与接触。仙子在侧前方，留足环境视野；一个臂长距离与人物仅占画面3%不能同时要求。衣发响应气流并有滞后，转弯自然引领，不拉长肢体追镜头。原图没有人物时标注添加/重构，不称还原。

速度感来自近快远慢的视差、连贯透视遮挡、自然加减速及轻微侧倾，不依赖眩晕翻滚和全屏模糊。光随阴影与开阔区域变化。

## 3. 宏大场景展示

选择一种最适合的主运动，不默认穿门：

| 运镜 | 图片条件 | 张力来源 |
|---|---|---|
| 慢推进 | 入口、深处焦点、通道 | 体量增大、空间压迫 |
| 横移 | 前景柱廊、屋檐、树枝 | 遮挡解除、前后视差 |
| 拉远 | 局部或人物突出 | 揭示局部所属整体 |
| 抬升/轻仰 | 多层结构、上下跨度 | 展开垂直尺度 |
| 固定/微动 | 构图强、云水织物丰富 | 巨构静止与生命感对照 |

人物动作克制，动态有重量。光影用局部反射、透光与缓慢遮挡，不硬加闪电、爆炸或昼夜转换。结尾停在值得观看的构图，不强行高潮。

## 提示词顺序

1. 参考用途与保留的视觉锚点，必要的视角重构。
2. 起点、主运动、真实路径与镜头朝向。
3. 两至四个自然阶段，或稳定持续的单阶段，不强制精确秒数。
4. 环境/人物动态、光与材质响应、结束状态。
5. 针对性约束：结构、身份、牵手、标记或剪辑连续性。

每个效果都应有承载对象，不同时要求超高速、缓慢旋转、固定视角等互相冲突的动作。
