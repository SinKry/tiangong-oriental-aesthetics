# 生图：东方史诗画面的四项公式

## 奇观主视觉

用一个可见且明确的视觉中心统摄画面，例如横跨云谷的门楼、托起宫城的巨树、山岳般的玉龙、云海上方的殿群。主视觉可以是对象，也可以是特殊空间关系，其他细节围绕它组织。

主题创作默认天空与云海，主体名不决定栖息环境。“月下龙宫”可以是云上重阙、悬空水晶殿、龙形巨构承托的宫城；珍珠和珊瑚纹只提供材质意象，不自动引入海水。用户明确指定其他环境才切换；逆向素材则忠实于实际画面。

东方美学落在形态、材质和空间秩序上：重檐斗拱、园林框景、玉石透光、青铜铸纹、漆木、山水留白、虚实层次等按主题选用。不同地域、时代风格不随意混成符号堆。不需要建筑的题材不强加宫阙。

## 超常尺度

提供可比较的证据，不仅写“巨大”：小门窗嵌入宽阔立面、普通楼阁排列在巨兽背上、瀑布穿过多层云带、远景重叠缩小、近处构件被画框截断。

复杂结构遵循大形体 → 中型殿宇/山体 → 局部纹理的层级，留出通道与负空间，避免全图同等密度和亮度。完整悬空岛或高位俯视并非禁用，但出现模型感时优先改视点和尺度参照，而非继续增加小楼。

环境优先时先写环境和光影，人物后置简写。面部特写会占据画幅，不与环境占绝大多数冲突；百分比只作辅助，景别、位置和人物相对建筑的比例更重要。

## 强构图

先确定观看者位置、视线终点、前中后景和最强对比区域，再选构图。对称提供仪式感，斜线提供冲力，框景提供层次，侧向透视提供纵深，留白提供辽阔。不固定超广角仰视。

包含后续飞行任务时，底图可有可辨入口、通道和终点，不为展示全部节点牺牲电影构图而变成等距沙盘。背面路线不可见时承认推演或补图需求，不声称单图能确定全部三维结构。

## 光色层次：学习关系，不固定配色

按因果顺序构造光影：

1. **光源**：位置、方向、尺度、软硬，例如开口背后的日光、侧上方月光、厚云漫射天光、殿内局部灯火。
2. **受光与遮挡**：谁被照亮、谁遮住谁、明暗交界在哪里，最强对比服务哪个视觉中心。
3. **材质响应**：薄纱透射、羽缘透亮、玉石半透、金属反射、漆面柔亮、石材漫反射；选最有价值的两三处，不全写。
4. **参与介质**：云雾在哪里散射光、哪些通道通透；体积光需要光源与介质，不默认全屏光柱。
5. **颜色与纵深**：主色建立氛围，辅助色区分空间或材质，强调色集中焦点。远景对比通常随空气透视降低，但颜色随环境变化，不固定蓝灰。相近色也能形成层次，不强制冷暖配对。

灵感可来自银白漫射的玉宫、月光穿透青绿玉柱的云上龙宫、暗紫夜色中的殿群、雨后墨色悬空山城的一束侧光、金橙夕照。它们只是例子，不是固定五套；要改变光源与明暗组织，不只是替换颜色名称。

“体积光、丁达尔效应、电影感、8K”不能代替具体照明。强光可耀眼，主要形体仍需可辨；保留细节不意味着取消冲击力。

## 五组方案的差异

保持主题共性，至少改变两项：奇观形态、建筑与自然关系、尺度策略、机位构图、天气环境、光源配色。五组可以同色系但空间/照明不同；不要固定为金蓝紫绿白五连。

## 提示词组织

第一段：画幅风格 → 主视觉 → 尺度证据。
第二段：机位布局 → 前中后景 → 人物位置（如有）。
第三段：光源 → 材质响应 → 明暗色彩与纵深。
只在必要时加针对性排除项，不堆长负面清单。

静态图写瞬间形态，如披帛扬起、双翼舒展、云带遮住基座。不写镜头推进旋转等时间动作。逆向任务先忠于图像，增强版明确标为改编。
